# 🧠 Финансовый мозг

Семейный бюджет, кредиты, счета в банках, данные рынка Армении и AI-помощник.
Интерфейс на русском, английском и армянском.

**Вкладки:** Семья · Доходы/расходы · 🧾 Операции · Счета · Кредиты · Рынок · Аналитика · 🔮 Прогноз · Лишние деньги · 🧮 Калькуляторы · 🔔 Напоминания.

- **Вход обязателен.** Без авторизации видна только форма входа, API данных закрыто. У нового аккаунта все данные нулевые.
- **🔮 Прогноз «что будет»:** события по месяцам (премия, покупка, пополнение или снятие денег, изменение дохода или расходов, новая ставка, досрочное погашение, закрытие кредита, новый кредит). Результат через 3/6/9/12/18/24/36 месяцев в сравнении с вариантом «ничего не менять», с учётом инфляции и роста дохода, а также таблица доходов и расходов по месяцам.
- **Калькуляторы:**
  - зарплата «грязными ↔ чистыми» по Налоговому кодексу РА на 2026 год (подоходный налог 20%/10% IT, пенсионный взнос, штамповый сбор, медстраховка);
  - кредит как в банке: аннуитет или дифференцированный платёж, комиссии, страховка, эффективная ставка и полный график;
  - ипотека с возвратом подоходного налога по правилам 2026 года;
  - аванс (досрочное погашение): сократить срок или уменьшить платёж.
- **Напоминания:** коммунальные платежи, техосмотр, страховка, налоги и свои. Кредиты добавляются автоматически. Раз в день по cron бот присылает уведомления в Telegram.
- **Быстрый выбор названий:** кнопки-подсказки и выпадающие списки; категория и тип подставляются сами.

**Стек:** Node.js + Express · SQLite (better-sqlite3) · чистый HTML/CSS/JS · node-cron · Groq / Gemini.

## 📅 Даты и регулярные платежи

У доходов, расходов и кредитов есть даты «действует с / до» (можно указать прошлое). Вкладка «🎯 Регулярные и цели»: платёж или накопление с частотой (неделя/месяц/квартал/год) от одной даты до другой, с целью и счётом. Уже прошедшие платежи считаются, прогноз и напоминания (включая Telegram) учитывают даты окончания. История на «Обзоре» до первой ежедневной записи восстанавливается по датам.

## 📊 Обзор (главная)

Каждый день, когда вы открываете приложение, сохраняется снимок: доход, расходы, долги, накопления, капитал. На вкладке «Обзор» можно выбрать период (1/3/6 мес, год, всё или свои даты) и увидеть графики истории с прогнозом на 12 месяцев, доходы/расходы по месяцам, структуру трат, долги и платежи на ближайшие 14 дней.

## Быстрый старт

Нужен Node.js 18.17 или новее (`node -v`).

```bash
cd projects/personal/finbrain
npm install
cp .env.example .env      # Windows: copy .env.example .env
npm start
```

Откройте http://localhost:3000. Зарегистрируйтесь кнопкой 👤: после входа бюджет хранится на сервере и доступен с любого устройства.

Для разработки используйте `npm run dev`: сервер сам перезапускается при изменении файлов.

## Настройка `.env`

| Переменная | Зачем |
|---|---|
| `GROQ_API_KEY` | AI-помощник. Бесплатный ключ: https://console.groq.com/keys |
| `GEMINI_API_KEY` | Запасной AI: включается, если Groq упёрся в лимит. Ключ: https://aistudio.google.com/apikey |
| `FINNHUB_API_KEY` | Биржа (SPY, DIA, QQQ, IWM). Бесплатный ключ: https://finnhub.io/register |
| `TELEGRAM_BOT_TOKEN` | Напоминания в Telegram. Создайте бота у @BotFather → /newbot |
| `REMINDER_CRON` | Когда рассылать напоминания (по умолчанию каждый день в 9:00 по Еревану) |
| `ADMIN_TOKEN` | Секрет для ручного обновления рынка через API |
| `AI_PER_HOUR` | Сколько вопросов AI в час разрешено одному пользователю (по умолчанию 20) |
| `MARKET_CRON` | Когда обновлять рынок (по умолчанию каждый день в 8:17 по Еревану) |
| `COOKIE_SECURE` | Поставьте `true`, когда сайт работает по HTTPS |

Без AI-ключей приложение работает полностью, только кнопки 🤖 не будет.

## Что обновляется само, а что вручную

| Данные | Источник | Как |
|---|---|---|
| Курсы ЦБ Армении (USD, EUR, RUB и др.) | Официальный API ЦБ `api.cba.am` | Автоматически раз в день |
| Биржа | Finnhub (если есть ключ) | Автоматически раз в день |
| Ставка ЦБ, вклады, ипотека, потребкредиты | `data/banks.json` | **Вручную**: у банков нет открытого API |

Чтобы обновить ставки банков, отредактируйте `data/banks.json` (там уже данные на 4–5 ноября 2026) и выполните:

```bash
npm run market:update
```

Или без остановки сервера:

```bash
curl -X POST -H "x-admin-token: ВАШ_ADMIN_TOKEN" http://localhost:3000/api/admin/refresh-market
```

```

├─ db.js             SQLite: users, sessions, budgets, market, history

├─ reminders.js      Напоминания: расчёт дат, Telegram-бот, ежедневная рассылка
├─ jobs/market.js    Сбор курсов ЦБ и биржи, сводка на 3 языках
├─ data/banks.json   Ставки банков и ЦБ (правится вручную)
├─ data/finbrain.db  База (создаётся сама, в git не попадает)
└─ public/           index.html, app.js, style.css
```

## API

| Метод | Путь | Описание |
|---|---|---|
| POST | `/api/register`, `/api/login`, `/api/logout` | Аккаунт (email + пароль, сессия в HttpOnly cookie) |
| GET | `/api/me` | Текущий пользователь и включён ли AI |
| GET / PUT | `/api/budget` | Бюджет пользователя (JSON) |
| GET | `/api/market`, `/api/history` | Данные рынка и история курсов |
| POST | `/api/ai` | Вопрос AI-помощнику (нужен вход; лимит в час) |
| GET / DELETE | `/api/telegram` | Статус Telegram / отключить |
| POST | `/api/telegram/link`, `/api/telegram/test` | Ссылка для подключения бота / тестовое сообщение |
| POST | `/api/admin/refresh-market` | Обновить рынок (заголовок `x-admin-token`) |
| POST | `/api/admin/send-reminders` | Разослать напоминания сейчас (заголовок `x-admin-token`) |

## Импорт из Excel

Вкладка 🏦 Кредиты → «📥 Импорт из Excel». Загрузите `.xlsx`, в котором есть:
- лист **«Долги»**: договор, тип (ставка в тексте, например «21,4%»), срок платежа, сумма к закрытию и колонки-месяцы с планом платежей;
- лист **«Настройки»**: подписи в колонке A и значения в колонке B (зарплата, ипотека, расходы «… в месяц», наличные, возврат налога, ставка вклада, дата цели);
- лист **«План»**: разовые траты по месяцам.

Шаблон с примером и листом «Инструкция»: `public/samples/finbrain-template.xlsx` (в приложении — ссылка «Скачать шаблон»).

То же самое из терминала, прямо в локальную базу:

```bash
npm run db:status                                    # что сейчас лежит в базе
npm run db:status -- --email you@mail.am             # подробно по одному пользователю
npm run db:import -- --email you@mail.am --file ~/Downloads/plan.xlsx --dry-run   # показать «было → станет», ничего не меняя
npm run db:import -- --email you@mail.am --file ~/Downloads/plan.xlsx --mortgage-balance 30000000 --mortgage-rate 12.9
```

Записи с такими же названиями, как у вас в базе (например, «Зарплата»), не дублируются. Чтобы заменить их значениями из файла, добавьте `--overwrite`.

Сначала показывается предпросмотр с галочками, и только после подтверждения данные записываются в вашу базу. Платежи по долгам в прогнозе идут точно по графику из таблицы. Повторный импорт заменяет прошлый, а то, что вы ввели вручную, не трогает. Сам файл на сервере не сохраняется.

## Telegram-напоминания

1. В Telegram откройте @BotFather → `/newbot` → получите токен.
2. Вставьте токен в `.env` как `TELEGRAM_BOT_TOKEN=...` и перезапустите сервер.
3. В приложении откройте вкладку 🔔 Напоминания → «Подключить Telegram» → в боте нажмите **Start**.

Каждый день в 9:00 бот присылает платежи на сегодня и те, до которых осталось столько дней, сколько указано в поле «Напомнить за». Кнопка «✓ Оплачено» убирает текущий платёж до следующего периода.

## Безопасность и приватность

- Пароли хранятся только как bcrypt-хэш. Сессия — случайный токен в HttpOnly cookie на 30 дней.
- На вход и AI действуют лимиты запросов. Заголовки CSP и X-Frame-Options включены.
- В AI уходит только сводка цифр без имён детей и названий кредитов. Учтите: бесплатный Gemini может использовать запросы для улучшения своих моделей.
- Бэкап — это просто копия файла `data/finbrain.db`.

## Размещение в интернете

Подойдёт любой VPS или PaaS с Node.js и постоянным диском, на котором будет лежать файл SQLite. На сервере:

1. `npm ci --omit=dev`, затем заполните `.env` и поставьте `COOKIE_SECURE=true`.
2. Запустите через `pm2 start server.js --name finbrain` или systemd.
3. Перед приложением поставьте Nginx или Caddy с HTTPS.

Ставки налогов указаны на 2026 год: проверяйте изменения на src.am.

Это обучающий калькулятор, а не индивидуальная финансовая консультация.
